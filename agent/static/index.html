SCPPrint.

จัดการงานพิมพ์และตรวจอุปกรณ์ USB ในวงแลน

ยังไม่ได้เชื่อมต่อ

เชื่อมต่อ Agent

ใช้โทเคนจาก /etc/scpprint/api.env บนกล่อง โทเคนจะเก็บในหน่วยความจำของหน้านี้เท่านั้น

เชื่อมต่อเพื่อดูสถานะและส่งงานพิมพ์
CUPS SCHEDULER—บริการรับงานพิมพ์
PRINT QUEUES—คิวที่ตั้งค่าไว้
PENDING JOBS—งานที่ยังไม่เสร็จ
USB DEVICES—อุปกรณ์ทั้งหมด รวม USB hub

เครื่องพิมพ์

แสดงคิว CUPS; ป้าย USB บอกชนิดคิว โปรดดูรายการอุปกรณ์ด้านล่างประกอบ

ยังไม่มีข้อมูล

อัปเดตอัตโนมัติทุก 15 วินาทีหลังเชื่อมต่อ

ส่งงานพิมพ์

PDF จะแปลงผ่านไดรเวอร์บนเซิร์ฟเวอร์ ลูกข่ายไม่ต้องติดตั้งไดรเวอร์

จำกัดขนาดไฟล์ตามการตั้งค่าเซิร์ฟเวอร์

RAW ต้องเป็นข้อมูลที่เครื่องพิมพ์เข้าใจอยู่แล้ว เช่น PCL/ESC/POS การส่ง PDF เป็น RAW จะไม่แปลงไฟล์ให้

Clear Print Queue

แก้ปัญหากระดาษติดที่เครื่องก่อน แล้วล้างงานที่ค้างในคิวที่เลือก

ยกเลิกทุกงานในคิวนี้ รวมงานของผู้ใช้อื่น งานที่ส่งถึงหน่วยความจำเครื่องพิมพ์แล้วอาจยังพิมพ์ต่อ

เปิด-ปิดเครื่อง USB ใหม่?

ระบบ Auto-heal จะเปิดคิวที่ Paused ให้เมื่ออุปกรณ์กลับมาเชื่อมต่อ โดยเก็บงานที่ค้างไว้ ล้างคิวเฉพาะเมื่อคุณต้องการยกเลิกงานจริงๆ

ข้อมูลจากระบบ

คำสั่ง lpstat -p -d และ lsusb บนกล่อง Armbian
